# RESTORE（非常時の入り口）

このフォルダは、PCが壊れた・買い替えた等でゼロから環境を作り直す
必要が生じたときのための入り口です。難しいことを考える必要はありません。
上から順に、終わったら [ ] にチェックを入れながら進めてください。

---

## 1. まずやること：Debianをインストールする

- [ ] USBメモリをPCに挿す（予備USBの保管場所は◯◯／◯◯を確認）
- [ ] そのUSBから起動し、画面の指示に従ってDebianをインストールする

USBが見当たらない・使えない場合は新規作成する。
`make-install-usb/README.md` を見てください。

---

## 2. 次にやること：dotfilesで環境を復元する

Debianのインストールが終わったら、以下のリポジトリの手順に従って
環境を復元します。

- [ ] リポジトリを開く: `~/src/github.com/minorugh/dotfiles`
- [ ] `dotfiles/README.md` を上から順に読み、その通りに進める

このREADMEの通りに進めれば、Dropbox・SSH鍵・アプリ設定などが
自動で復元されます。

---

## 3. 参考：env-import について

dotfilesの復元手順の中で `env-import` というリポジトリを使います。
これはGPGの秘密鍵をインポートし、Dropboxに保存された秘密ファイル
（SSH鍵など）を復元するためのものです。難しい場合は覚えなくてよく、
`dotfiles/README.md` の手順通りに進めば自動的に使われます。
