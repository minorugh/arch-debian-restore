# ThinkPad 目利き用 Live USB 操作マニュアル

このマニュアルは、中古の ThinkPad が届いた直後や、店頭でハードウェアの状態を 5 分で完璧に見抜くための検証手順書です。

## 🚀 1. 準備と起動手順
1. 本作戦用の 32GB USB メモリをメイン機に挿し、`make-live-usb.sh` を実行して EndeavourOS の Live 環境を上書き作成します。
2. テスト対象の ThinkPad に USB を挿し、**電源オンと同時に [F12] キーを連打** します。
3. Boot Menu が表示されたら、挿した USB メモリを選択してエンターを押します。
4. しばらく待つと、自動的に綺麗なデスクトップ環境（GUI）が立ち上がります。

## 🔍 2. 5分間ハードウェア健康診断メニュー

### ① 液晶画面のチェック（ドット抜け・シミ・色むら）
* **手順**: プリインストールされている Firefox ブラウザを起動し、アドレスバーに `about:blank` と入力して真っ白な画面を表示します。
* **目利きポイント**: 画面を凝視し、「黒い点（ドット抜け）」や「不自然に白いモヤ（圧迫痕による光むら）」がないかチェックします。Emacs で文字を凝視する上で、画面が綺麗（Be-StockのAランク相当）であることは最重要です。

### ② SSDの寿命・消耗度チェック（超重要）
* **事前準備**: Live環境に `smartctl` が入っていない場合があるので、まず以下でインストールします。
  ```bash
  sudo pacman -Sy --noconfirm smartmontools
  ```
* **手順**: デスクトップでターミナル（端末）を開き、以下のコマンドを一発叩きます。
  ```bash
  sudo smartctl -a /dev/nvme0n1
  ```
* **目利きポイント**: 出力されたテキストの中から以下の項目を探します。
  * **`Percentage Used`**: これまでの累積消耗度です。ここが `10%` 以下などであれば、前のオーナーがあまり書き込みを行っておらず、新品同様に長寿命であることを意味します。
  * **`Available Spare`**: 予備領域の残量です。通常は `100%` になっていれば問題ありません。

### ③ CPU温度とファンの挙動チェック
* **事前準備**: `sensors` が入っていない場合があるので、まず以下でインストールし、センサーを検出します。
  ```bash
  sudo pacman -Sy --noconfirm lm_sensors
  sudo sensors-detect --auto
  ```
* **手順**: ターミナルで以下のコマンドを叩きます。
  ```bash
  sensors
  ```
* **目利きポイント**: アイドリング（何も作業をしていない状態）で、各コアの温度が **40°C〜50°C前後** に収まっているか確認します。もし起動直後から 70°C を超えているような個体は、内部のファンに埃が詰まっているか、CPUグリスが完全に干からびているハズレ個体の可能性があります。

### ④ キーボード＆トラックポイント（赤ポチ）チェック
* **手順**: ターミナル、または標準のテキストエディタを開き、すべてのキー（特に [Ctrl]、[Alt]、[Enter]、[Space]、およびファンクションキー）を順番に入力します。
* **目利きポイント**: 入力が抜けるキーがないか、赤ポチでカーソルが滑らかに動くか、キーの押し心地（クリック感）にへたりがないかを指先で確認します。

## 🛠️ 3. 実機への本番移行ロードマップ（USBテスト合格後）
テストをクリアし、実機への Arch Linux の本番導入が決まったら、じっくり腰を据えて本番用の `Makefile`（Emacs 31.1 自作ビルドや日本語環境 bootstrap 統合スクリプト）を走らせ、最強の Arch 環境を育てていってください。
